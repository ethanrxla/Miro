The Campaign autoload tracks current floor, committed sigils, story milestones, boss outcome and ending completion in memory. Restart restores the current floor entry state; a new run clears progress. Inventory/casualties do not yet carry between floors, and there is no disk save. Launching a later floor directly is an independent development entry point. The final viewpoint completes Level 5; Enter then starts a new run.

## Editing and playing

Open `scenes/levels/level_02.tscn` through `level_05.tscn` in Godot, or run `./Play Level.ps1 -Level 2` (accepts 1–5). Controls follow the intro; E interacts and Tab skips dialogue. Skipping applies the same milestone as finishing dialogue. Required stations block out-of-order progress; sigils and milestones cannot be consumed twice.

Each blueprint contains floor bands, gaps, shelves, interactables, guards, spawn, story beats, stations, dependencies and source references. `LevelPlan` contains editor markers for story beats and unfinished systems. `scripts/scaffold_level.gd` handles the shared milestone flow; `scripts/scaffold_art.gd` draws placeholder masonry.

Regenerate saved later-floor scenes with Godot's `--headless --path . --script res://tools/build_remaining_levels.gd`. This overwrites the generated scenes, so preserve manual scene edits before regenerating or make layout changes in the blueprints.

## Verification

`Run Checks.ps1` includes the Level 1 playthrough/control/scaffold regressions and `tools/test_remaining_levels.gd`. The latter walks and climbs each floor with real player physics, interacts with all stations, verifies source paths, checks idempotent completion and reaches each exit alive. These checks validate the blockout progression; focused security and boss suites additionally verify concealment, occlusion, interrupted hacking, pause/reset, alternating attacks, vulnerability and fatal dialogue completion. The traversal suite defeats the boss with movement/jump/shank inputs. The ending suite verifies actual Tab skip, watching to completion, pause, repeat protection, identical milestone results and campaign retry/new-run resets. Final cinematic art production remains unfinished.

## Current interaction revisions

The latest user direction supersedes shadow-only stealth: press 2 anywhere after obtaining supplies, move at 55% speed for up to 5 seconds, then recharge for 8 seconds. Touching a living guard immediately blows cover. See [current gameplay decisions](GAMEPLAY_DECISIONS.md) for cancellation and timer rules. Shadow recesses remain environmental art and route landmarks, not activation requirements. Later-floor guards now provide limited gun ammunition when searched.
